Comment vérifier chaque lot

  • Repasser le banc d'inventaire (outils/DossierTest.kt copié dans src/test, puis retiré) et outils/mesures.py : les critères d'acceptation sont écrits pour ses sorties (contrastes, cibles, accessibilité, police).
  • Le banc de l'app (gradlew testDebugUnitTest) reste vert ; deux de ses tests échouent entre minuit et une heure (heure du conteneur), sans lien avec ces recos.
  • Sur le Pixel : TalkBack (navigation par titres, annonces), police à 200 %, écran verrouillé pendant un enregistrement, un vrai appel WhatsApp avec la pastille.
  • Écarts à reporter dans les issues : #32 (P18, initiales dans le protocole) ; #31 n'est touché par aucune reco.
